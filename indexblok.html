Encrypted Vault & Anti-Inspect Shield Aktif

Koneksi Database Supabase Terproteksi

Kredensial Supabase dienkripsi dengan cipher acak (Zero-Plaintext) sehingga tidak dapat diintip dari kode sumber maupun inspeksi elemen.

Vault Siap Dihubungkan

Wajib Agar Data Muncul di Private Tab / Incognito & Semua Pengunjung:

Blogger berfungsi sebagai GUI dan Supabase sebagai Database. Agar tab Incognito / Private mengenali database Anda tanpa bergantung pada memori browser lokal, klik Enkripsi & Hubungkan lalu salin 1 Baris Kode Vault di bawah ini ke dalam kode Edit HTML Tema Blogger Anda.

Tempelkan baris ini di bagian atas <script> pada Edit HTML Tema Blogger Anda:
const _BK3_MASTER_EMBEDDED_VAULT = '';
SQL Schema + Strict Row Level Security (Supabase) 
create table if not exists public.edu_products (
  id uuid default gen_random_uuid() primary key,
  title text not null,
  category text not null,
  levels text[] not null default '{}',
  description text,
  image_url text default '',
  price integer not null default 0,
  is_paid boolean not null default false,
  lynk_url text,
  youtube_url text,
  pdf_url text,
  demo_url text,
  rating numeric(2,1) default 4.9,
  reviews_count integer default 120,
  cover_theme text default 'from-blue-600 to-indigo-700',
  lynk_clicks integer default 0,
  created_at timestamptz default now()
);

alter table public.edu_products add column if not exists image_url text default '';

create table if not exists public.edu_categories (
  id text primary key,
  label text not null,
  icon text default 'folder-open',
  is_visible boolean default true,
  sort_order integer default 10
);

create table if not exists public.edu_chat_logs (
  id uuid default gen_random_uuid() primary key,
  session_id text not null,
  sender text not null,
  message text not null,
  created_at timestamptz default now()
);

create table if not exists public.edu_visitor_logs (
  id uuid default gen_random_uuid() primary key,
  visitor_hash text not null,
  location_label text,
  device_type text,
  os_name text,
  browser_name text,
  screen_res text,
  timezone text,
  visited_at timestamptz default now()
);

create table if not exists public.edu_portal_settings (
  setting_key text primary key,
  setting_value jsonb not null,
  updated_at timestamptz default now()
);

alter table public.edu_products enable row level security;
alter table public.edu_categories enable row level security;
alter table public.edu_chat_logs enable row level security;
alter table public.edu_visitor_logs enable row level security;
alter table public.edu_portal_settings enable row level security;

create policy "Public Read Products" on public.edu_products for select using (true);
create policy "Auth Manage Products" on public.edu_products for all using (true) with check (true);
create policy "Public Read Categories" on public.edu_categories for select using (true);
create policy "Auth Manage Categories" on public.edu_categories for all using (true) with check (true);
create policy "Insert and Read Chat Logs" on public.edu_chat_logs for all using (true) with check (true);
create policy "Insert and Read Visitor Logs" on public.edu_visitor_logs for all using (true) with check (true);
create policy "Manage Portal Settings" on public.edu_portal_settings for all using (true) with check (true);
